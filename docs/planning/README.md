# Planning Area

This folder is the non-operational planning area for future `exec-ctrl` enhancements.

Use it to capture:

- candidate method improvements
- future prompt, template, or example additions
- automation ideas that are not active work yet
- roadmap notes for how agents may strengthen `exec-ctrl` over time

Do not use this folder for live initiative execution control.

Operational evidence for active and completed bounded refinements belongs in `docs/exec_ctrl/`.

## Promotion rule

Keep an idea here while it is still planning-only.

When the work becomes active, promote it into a bounded initiative under `docs/exec_ctrl/` and treat the planning note as input rather than proof of execution.
