# Contract discrepancy review

Use for material disagreements, inside the current task when possible.

| Requirement / expected behavior | Entry point and callers | Implementation / state / side effect | Docs / tests | Discrepancy and impact | Evidence / confidence | Owner / disposition |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

Record the authority establishing intended behavior, the relevant source snapshot,
the reproducing or discriminating check, and verification after correction.
Include denied paths, retries, concurrency, errors, compatibility and partial
writes only where they affect this contract. A suspected discrepancy stays a
hypothesis until its evidence supports the conclusion.
