# Finding template

- ID, title and source location:
- Expected contract versus actual behavior:
- Evidence/reproduction, subject revision and environment:
- Impact, exposure, severity rationale and confidence:
- Cause: confirmed / hypothesis / unknown:
- Proposed correction and regression/negative check:
- Owner, state, target milestone and canonical issue:
- Disposition: fixed / open / false positive with evidence / approved exception:
- Exception source, approver, expiry and compensating control if applicable:
- Redaction and disclosure constraints:

Do not include secret values, private customer payloads or unnecessary exploit
details in public records. A scanner finding and a confirmed reachable defect
are different claims; state which the evidence supports.
